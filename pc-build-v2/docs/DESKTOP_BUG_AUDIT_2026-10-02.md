# Проверка ПК-клиента CR Tools V2 — 2 октября 2026

Проверена текущая реализация `pc-build-v2`: главная страница, захват и профили,
мастер настройки, мониторинг, окно соперника, Twitch, прогнозы, название трансляции,
OBS, настройки, авторизация и обновления. Проверка включала чтение кода основных
потоков, сопоставление ответов streamer API с серверной реализацией и автоматические
проверки. Это не проверка установленного Windows-приложения на реальном экране.

## Результаты проверок

- До изменений: 321 тест Vitest прошёл, один Windows-зависимый тест пропущен.
- После изменений: 336 тестов Vitest прошли в 58 файлах, один тест пропущен.
- Python: 37 тестов прошли; предупреждения `RuntimeWarning` считались ошибками.
- TypeScript: `tsc --noEmit` прошёл, включая проверку в рабочей папке.
- ESLint и Prettier прошли.
- `build:app` прошёл, включая проверку четырёх самостоятельных sandboxed preload.

Linux-зависимости установлены в отдельной папке `/tmp`, Windows `node_modules` и
переносимый Python приложения не заменялись. Сборка проверена в копии исходников,
чтобы не перезаписывать существующую сборку владельца. При копировании исключён
старый автоматически созданный `.pytest_cache`.

## Проверки, требующие Windows

Дополнительно исправлено закрытие диалога профиля при выделении текста: браузер
направлял `click` общему предку после нажатия в поле и отпускания на фоне.
Закрытие теперь требует начала и окончания жеста на фоне; отменённый жест
сбрасывается. Это применяется к созданию, переименованию, копированию и удалению
профилей. Четыре новые проверки воспроизводят оба направления перетаскивания,
обычный клик по фону и отмену жеста. До исправления три проверки падали; после
изменения все 36 проверок главного интерфейса и стримера прошли. TypeScript,
ESLint и Prettier изменённых файлов также прошли.

При последующем запуске разработки найдено отсутствие оформления: HTML-политики
`style-src 'self'` блокировали вставляемые Vite теги стилей. Добавлен плагин,
работающий только при `dev`: случайный nonce разрешает стили Vite и скрипт React
Refresh; соединение обновлений разрешено для адреса локального сервера. Это
применяется к авторизации, главному окну, мастеру настройки и виджету.
Исходные HTML и политики готовой сборки остаются строгими. Пять дополнительных
проверок преобразования HTML прошли; TypeScript, ESLint изменённых файлов и сборка
с проверкой preload прошли. Содержимое четырёх готовых HTML отдельно проверено:
nonce разработки отсутствует, CSS подключена внешними файлами, у виджета сохранён
`connect-src 'none'`.

Фактическое время появления списка, первого кадра и окна соперника пока не измерено:
Windows-мост недоступен в этой сессии. Удалены конкретные причины лишнего ожидания,
но мгновенный первый кадр для любого источника не гарантируется.

На реальном ПК нужно проверить открытые и свёрнутые окна, исчезновение источника во
время подготовки, быструю смену нескольких окон, мониторы с масштабом 100/125/150%,
сохранение нового профиля после мастера, перепривязку с другими пропорциями,
повторный запуск после скрытия виджета, Twitch OAuth, прогнозы и browser sources OBS.
Тесты чистой логики не заменяют эти проверки оборудования и внешних сервисов.

Установщик и публикация обновления в эту задачу не входили. Изменения сохранены в
исходниках; работающие пользовательские установки получат их после сборки и
публикации соответствующей версии.
